# Screen Test Pro replacement files

Upload these files to the root of the existing `screen-test-pro` repository.

## Files
- `index.html`: responsive display tester, colour patterns, grid, instructions, limitations, FAQ, and site navigation.
- `about.html`, `privacy-policy.html`, `terms.html`, `contact.html`: supporting pages.
- `robots.txt`, `sitemap.xml`: basic crawl guidance and sitemap.
- `ads.txt`: existing publisher record retained.

## Deployment
1. Keep the GitHub repository and any deployment configuration files that are not included here.
2. Replace the existing `index.html` and `README.md`; add the new pages and crawl files.
3. Preserve `ads.txt` or confirm the uploaded file matches the existing record.
4. Commit to the production branch and wait for Vercel to deploy.
5. Test each colour button, grid, exit controls, and every footer link on desktop and mobile.

The AdSense loader is present, but this package does not add ad slots or imply approval. AdSense approval and serving must be confirmed in your own AdSense account. Review the legal pages against your actual analytics/advertising configuration before publishing.
